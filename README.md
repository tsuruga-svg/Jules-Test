# パスワード生成ツール (Password Generator)

## 概要

指定した単語をベースに、推測されにくい強固なパスワードを生成するWebアプリケーションです。
覚えやすい単語を元に、文字の置換やランダムな文字を追加することで、セキュリティと記憶しやすさを両立したパスワードを作成します。

このプロジェクトはDocker化されており、簡単なコマンドでローカル環境で実行できます。

## 主な機能

- **ベース単語**: 好きな単語をパスワードの元として使用できます。
- **文字の自動変換**: `l→1`, `o→0`, `s→5`, `q→9`, `b→8` のルールに基づき、単語の文字を自動で変換します。
- **カスタマイズ可能な条件**:
  - **文字種**: 英語（大文字/小文字）、数字、記号の使用を選択できます。
  - **文字数**: 8, 10, 12文字、または任意の文字数を指定できます（4〜128文字）。
- **クリップボードへのコピー**: 生成したパスワードをワンクリックでコピーできます。
- **詳細なロギング**: アプリケーションの動作状況がコンソールに記録され、デバッグや保守が容易です。

## 実行環境のセットアップ (Docker)

このアプリケーションはDockerおよびDocker Composeを使用して簡単に起動できます。

1.  **リポジトリをクローンします**
    ```bash
    git clone https://github.com/your-username/password-generator.git
    cd password-generator
    ```
    *(注: 上記URLは実際のクローンURLに置き換えてください)*

2.  **Dockerコンテナをビルドして起動します**
    以下のコマンドを実行すると、必要なイメージがビルドされ、バックグラウンドでコンテナが起動します。
    ```bash
    docker-compose up --build -d
    ```

3.  **アプリケーションにアクセスします**
    Webブラウザで以下のURLを開いてください。
    [http://localhost:5001](http://localhost:5001)

4.  **コンテナを停止するには**
    ```bash
    docker-compose down
    ```

## 使用方法

1.  **ベースとなる単語を入力**:
    パスワードの元にしたい、覚えやすい単語（例: `Soccer`, `MyPassword`）を入力します。

2.  **使用する文字の種類を選択**:
    パスワードに含めたい文字の種類（大文字、小文字、数字、記号）を1つ以上チェックします。

3.  **文字数を選択**:
    希望するパスワードの長さを選択します。「その他」を選ぶと、自由な数値を入力できます。

4.  **「パスワードを生成」ボタンをクリック**:
    条件に基づいて、新しいパスワードが下に表示されます。

### 出力例

- **入力**:
  - ベースとなる単語: `Apple`
  - 文字数: 10
  - 文字種: 全て選択
- **出力例**: `_A5p@e1Pl!` (※出力は毎回ランダムに変わります)
